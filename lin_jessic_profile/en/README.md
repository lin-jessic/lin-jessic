## Selected Work

### 01 / PineNose

**Non-destructive Pineapple Ripeness & Variety Detection**  
*Graduation Capstone Project · Team Project*

PineNose explores a practical way to assess pineapple ripeness without cutting the fruit. A gas sensor array and machine-learning model classify ripeness into four stages, while an image-based pipeline identifies pineapple varieties. The system brings together Arduino, Raspberry Pi, Flask APIs, web interfaces, and mobile apps for farmers and consumers.

As the team leader, I contributed to system integration, sensing and data workflows, backend and database development, Docker deployment, feature integration, and debugging.

<sub>Arduino Mega 2560 · Raspberry Pi 3 · ExtraTrees · YOLOv8n · EfficientNet-B0 · Flask · Docker</sub>

[Repository](https://github.com/icguproject25-droid/electronic-nose-pineapple-ripeness-assessment)　·　[Project Website](https://icguproject25-droid.github.io/pinenose_official_site/)　·　[Competition Recognition](https://ysyct.wda.gov.tw/news_detail.php?id=120)

### 02 / FreqFuseNet

**3D Head-and-Neck Organ-at-Risk Segmentation**  
*Medical Image Segmentation · Research*

FreqFuseNet investigates scale mismatch between FFT and FcaNet frequency-feature branches in the segmentation of thin-wall head-and-neck organs at risk. The work studies scale normalization and residual fusion, with experiments and validation on SegRap2023.

I contributed to model experiments, ablation studies, baseline comparisons, result analysis, and manuscript-related work.

<sub>PyTorch · 3D CT · Deep Learning · Frequency-domain Features · SegRap2023</sub>

[Research Repository](https://github.com/Tiffanyxxx3238/freq-spatial-headneck-seg)　·　[medRxiv Preprint](https://www.medrxiv.org/content/10.64898/2026.07.09.26357642v2)
