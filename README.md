## Selected Work

### 01 / PineNose

**鳳梨電子鼻非破壞性熟度檢測系統**  
*長庚大學畢業專題 · 團隊專案*

PineNose 希望讓鳳梨成熟度判斷更容易量化，同時減少破壞性檢測。系統透過氣體感測器蒐集訊號，以機器學習辨識四個成熟階段；另一方面，運用影像辨識區分鳳梨品種。整體串接 Arduino、Raspberry Pi、Flask API、Web 介面與農民端／消費端 App，將感測、模型推論與使用介面整合成可展示的系統。

我在團隊中擔任組長，參與系統整合、感測與資料流程、後端與資料庫、Docker 部署、功能串接及測試排錯。

<sub>Arduino Mega 2560 · Raspberry Pi 3 · ExtraTrees · YOLOv8n · EfficientNet-B0 · Flask · Docker</sub>

[專案程式碼](https://github.com/icguproject25-droid/electronic-nose-pineapple-ripeness-assessment)　·　[作品網站](https://icguproject25-droid.github.io/pinenose_official_site/)　·　[競賽成果](https://ysyct.wda.gov.tw/news_detail.php?id=120)

### 02 / FreqFuseNet

**頭頸部危及器官 3D 醫學影像分割研究**  
*Medical Image Segmentation · Research*

FreqFuseNet 聚焦於頭頸部薄壁危及器官（Organs at Risk, OAR）的分割問題。研究探討 FFT 與 FcaNet 頻率特徵分支在融合時的尺度差異，透過尺度正規化與殘差融合設計，改善雙頻特徵整合，並使用 SegRap2023 資料集進行實驗與驗證。

我參與模型實驗、消融分析、基準方法比較、結果整理與論文相關工作。

<sub>PyTorch · 3D CT · Deep Learning · Frequency-domain Features · SegRap2023</sub>

[研究程式碼](https://github.com/Tiffanyxxx3238/freq-spatial-headneck-seg)　·　[medRxiv 預印本](https://www.medrxiv.org/content/10.64898/2026.07.09.26357642v2)
